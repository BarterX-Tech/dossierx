For people building with coding agents

Know what your software does. Even when an agent wrote it.

DossierX keeps the rules behind your software in one plain-English record. Review the rules, then give them to your coding agents before every change.

Where understanding breaks

The agent changed the code. What else did it change?

A small request can leave the product with two different answers.

  1. 01
    You ask for five retries.

    The request sounds simple.

  2. 02
    The agent edits the code.

    The tests pass, so the task looks finished.

  3. 03
    The old rule still says three.

    Now the code and the product record disagree.

  4. DX
    DossierX returns DX-042 to you.

    You decide whether the rule should change before it is approved again.
