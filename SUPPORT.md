# Support

- **Questions, usage help, general discussion:** use [GitHub Discussions](https://github.com/BarterX-Tech/dossierx/discussions).
- **Bug reports and feature requests:** use [GitHub Issues](https://github.com/BarterX-Tech/dossierx/issues) — please don't use Issues for open-ended questions, they're reserved for actionable bugs and feature requests.

For security vulnerabilities, see [SECURITY.md](SECURITY.md) instead of either of the above.
