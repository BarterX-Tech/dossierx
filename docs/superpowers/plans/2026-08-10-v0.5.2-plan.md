# v0.5.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the patch release that fixes the driver/forge deadlock blocking every future
release, canonicalises the version string, and retires the gate's recurring "byte I needed"
finding class — plus eight open issues.

**Architecture:** Six independent lanes, each landing as its own checkpoint commit against a
green `go test ./...`. Lanes 1, 5 and 6 touch gate machinery (test files, outside the shipped
binary); lane 2 touches the release configuration, the site and their guards together; lanes 3
and 4 are documentation and test guards. Release machinery lands last, after every lane is green.

**Tech Stack:** Go 1.26 test-file gate machinery, GoReleaser v2, GitHub Actions, TypeScript
(Vite/React site), YAML manifests.

**Spec:** `docs/superpowers/specs/2026-08-10-v0.5.2-design.md`

## Global Constraints

- **Branch is `release/v0.5.2`.** Never a bare `v0.5.2` — that is lane 1b's own rule, applied to
  this release.
- **`git status --porcelain` must be empty** at every commit boundary. The driver refuses a dirty
  tree (`Makefile:176`).
- **Every tracked file must be claimed by exactly one `surfaces.yaml` entry.** Adding any file
  means editing `surfaces.yaml` in the same commit, or `tests/surfaces_manifest_test.go` reddens.
- **`go test ./...` green before every commit.** A skip is a failure, not a pass.
- **The gate surfaces; it never fixes.** Nothing in this plan edits a gate verdict or receipt.
- **Never narrow coverage silently.** Where a check cannot run, it fails and says so.
- **Version pins move to `v0.5.2`** in the four pinned locations, one of which is inside
  `skills/dossierx/SKILL.md` — which makes the exported bundle a different bundle and requires the
  SILENT re-export notice in `CHANGELOG.md`.
